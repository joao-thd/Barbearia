# 💈 BluServs - Sistema de Agendamento para Barbearia

**BluServs** é um sistema online onde **clientes podem agendar horários** em uma barbearia, enquanto **barbeiros acessam seus agendamentos** através de um painel administrativo.

O projeto está em **desenvolvimento (versão 1.0)**. O backend já se comunica com o banco de dados MySQL, e a integração do frontend com a API está em andamento.

---

## 🚀 Tecnologias Utilizadas

### 🖥️ Frontend
- **Angular**
  - HTML
  - CSS
  - TypeScript

### 🛠️ Backend
- **C#**
- **ASP.NET Core Web API**

### 💾 Banco de Dados
- **MySQL**
- **Entity Framework Core** (ORM)

---
